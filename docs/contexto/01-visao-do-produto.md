# Visão do produto

## Produto

O R6 Hub é um hub visual de estratégias para jogadores de Tom Clancy's Rainbow Six Siege, inicialmente voltado a partidas Ranked.

Ele deve ajudar um jogador ou squad que já conhece o mapa e o bomb site, mas precisa decidir rapidamente:

- qual composição utilizar;
- como preparar o bomb;
- onde posicionar cada operador;
- qual é a responsabilidade de cada jogador;
- como executar o plano durante a rodada.

O produto não deve funcionar como uma enciclopédia. Sua proposta é transformar conhecimento disperso em um plano de jogo curto, visual e aplicável.

## Fluxo principal

**Mapa → Lado → Bomb site → Estratégia → Composição → Setup → Plano de jogo**

Após selecionar mapa, ataque ou defesa e bomb site, o usuário deve receber uma estratégia recomendada. A estratégia deve explicar não apenas quais operadores escolher, mas o que cada um precisa fazer.

## Conteúdo de uma estratégia

Uma estratégia pode conter:

- objetivo e resumo;
- composição recomendada;
- função contextual de cada operador;
- posições iniciais e posições importantes;
- instruções de uso de gadgets e habilidades;
- setup visual;
- etapas ordenadas do plano de jogo;
- marcações sobre uma planta do mapa.

Em defesa, o setup pode representar reforços, paredes abertas, rotações, linhas de visão, aberturas, escudos, câmeras, jammers, armadilhas e posições.

Em ataque, o plano pode representar spawn, drones, entrada, controle de salas, breaching, controle vertical, remoção de utilidade, flank watch, plant e pós-plant.

## Princípio de experiência

A informação mais importante deve aparecer primeiro. Detalhes adicionais podem ser expandidos.

O usuário deve conseguir chegar a uma estratégia compreensível em poucos segundos, inclusive em um contexto próximo ao início de uma partida.

## Direção do MVP

O MVP deve validar se o fluxo principal é realmente útil. Ele deve começar com poucos mapas e estratégias estruturadas manualmente, sem depender de inteligência artificial.

O desenvolvimento deve ser iterativo:

**implementar → testar → validar → melhorar**
