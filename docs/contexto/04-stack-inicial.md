# Stack inicial

## Tecnologias aprovadas

- **HTML5:** estrutura semântica das páginas.
- **CSS3:** identidade visual, layout, estados visuais e responsividade.
- **JavaScript Vanilla:** interações, navegação, carregamento de dados e manipulação dinâmica da interface.
- **JSON:** armazenamento inicial dos dados de mapas, bomb sites, operadores, composições e estratégias.

## Limites desta fase

- Não utilizar React, Vue, Angular ou outro framework de interface.
- Não implementar backend.
- Não implementar banco de dados.
- Não implementar autenticação.
- Não integrar Supabase.
- Não configurar deploy na Vercel.
- Não antecipar essas integrações sem autorização do responsável pelo produto.

## Diretrizes de organização

- Manter a solução pequena, clara e navegável.
- Separar estrutura, estilo, comportamento e dados.
- Evitar dependências e abstrações sem necessidade concreta no MVP.
- Evitar espalhar dados específicos do jogo diretamente pelo HTML ou JavaScript.
- Carregar mapas, bomb sites, operadores, composições e estratégias a partir de arquivos JSON.
- Preservar caminhos naturais de evolução sem implementar antecipadamente as tecnologias futuras.

## Evolução possível

Supabase poderá ser avaliado futuramente para persistência e serviços de backend. Vercel poderá ser avaliada para publicação. As duas possibilidades permanecem fora do escopo atual e dependem de autorização explícita.
