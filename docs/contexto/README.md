# Contexto do R6 Hub

Esta pasta concentra o contexto de produto necessário para manter o desenvolvimento consistente ao longo do projeto.

## Como usar esta pasta

- `01-visao-do-produto.md`: síntese do produto e do problema que ele resolve.
- `02-regras-e-limites.md`: decisões e restrições já apresentadas pelo responsável pelo produto.
- `03-decisoes-e-pendencias.md`: assuntos ainda não aprovados e perguntas em aberto.
- `04-stack-inicial.md`: tecnologias aprovadas e limites técnicos do MVP.

## Regra de atualização

Somente decisões confirmadas pelo responsável pelo produto devem ser tratadas como aprovadas. Propostas, hipóteses e recomendações devem permanecer identificadas como pendentes até validação explícita.

Antes de implementar ou alterar uma funcionalidade relevante, este contexto deve ser revisado. Quando uma decisão for aprovada, os arquivos desta pasta devem ser atualizados para evitar que conversas antigas se tornem a única fonte de verdade.
